TCP Сервер с автоотправкой сообщений
Простой TCP сервер на Python, который автоматически отправляет сообщения клиенту до тех пор, пока клиент не отправит команду "exit".

Особенности
Сервер автоматически отправляет нумерованные сообщения клиенту

Клиент может в любой момент отправить "exit" для завершения соединения

Реализована обработка разрыва соединения

Кросс-платформенное решение (работает на Windows, Linux, macOS)

Структура проекта
tcp-server-autosend/
├── server.py          # Серверная часть
├── client.py          # Клиентская часть
├── requirements.txt   # Зависимости (пустой, т.к. используется только стандартная библиотека)
└── README.md          # Этот файл

Использование
Запуск сервера
Откройте терминал и перейдите в директорию проекта

Запустите сервер:
python server.py
Сервер по умолчанию слушает на:

Хост: 0.0.0.0 (все интерфейсы)

Порт: 13337

Запуск клиента
Откройте другой терминал

Запустите клиент (укажите IP-адрес сервера):
python client.py

Важно: В файле client.py измените IP-адрес на IP-адрес вашего сервера:
HOST = "192.168.1.100"  # Замените на реальный IP сервера

Настройка сервера (server.py):
HOST = "0.0.0.0"  # Слушать на всех интерфейсах
PORT = 13337       # Порт для подключения

Настройка клиента (client.py):
HOST = "127.0.0.1"  # localhost для тестирования на одном компьютере
PORT = 13337        # Должен совпадать с портом сервера
